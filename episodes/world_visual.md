# 断層のグラヴェイン 美術・メカ設定書(作画用・第1版)

- 目的:作画や動画を描く人の想像がぶれないように、形、大きさ、位置、動き方を一つに決める。
- 各話の脚本のト書きは、この設定書を前提にする。脚本の台詞と食い違う場合は、台詞に合わせてこの設定書を直す。
- 数字は作画の基準。画面の見栄えのために多少誇張してよいが、比率(何が何より大きいか)は守る。

## 1. 世界の高さの関係(横から見た断面)

```
 高度 約2,500m       ── 空中要塞の都市の面(雲の上。いつも青空と陽光の中)
 高度 約1,300m       ── 中心の垂れ岩の先(雲の層の中に沈む)
 高度 約800〜1,800m  ── 低い雲の層(上から見ると白い雲海)
 高度 0m             ── 地上(茶色い大地。砂ぼこりで空は茶色くかすむ)
```

- 要塞は、第七区画の真上に、ほぼ動かずに浮かんでいる(9話・12話)。
- 地上から見上げると、雲の切れ間に、要塞の下側の岩の浮き島が黒い影として見える。施設の窓の灯りと赤い標識灯が点々と光り、細い滝が雲へ落ちている。
- 要塞から地上へ行くには、雲の層を突き抜けて降りる。雲の中は視界がゼロになる。1話でカイは、ここを片翼で落ちていく。
- 遠くの空には、要塞とは別の小さな浮き島がいくつか浮かんでいる(式典会場から見える)。

## 2. 空中要塞(『境界線の向こうへ』の都市像に合わせる)

### 全体の形
- 上半分は、**東西約20キロ・南北約14キロの楕円形**の土台の上に建つ、**近未来の白い都市**。白い高層の建物、丸いガラスの建物、高架の道とモノレールが並ぶ。
- 下半分は、**下へ不規則に尖った岩の浮き島**。地上から抜き取った岩の塊が、何本もの尖った岩になって垂れ下がる。岩肌には、錆びた足場、配管、施設の窓、赤い標識灯が張りつき、ところどころから細い滝が雲へ落ちている。**岩肌に青白い光の筋(葉脈のような光)はない。**
- いちばん長く垂れ下がった岩が**中心の垂れ岩**。都市の中央の真下にあり、先は高度約1,300メートルで、雲の層の中に沈んでいる。グラヴェインの格納区画は、この垂れ岩の中にある。
- 都市の縁は、**錆びたコンクリートと鉄の外装**の**外壁**(高さ約60メートル)がぐるりと囲む。白い街とは対照的に古びている。式典の日には、外壁に祝賀の旗と金色の飾りが並ぶ(1話)。

### 区画の配置(上から見た図)
```
            北
     ┌─────────────┐
     │  外周第一区画  │
 西 │第四 ┌───┐ 第二│ 東
     │区画│中央│区画│ ← 東の外壁に「搬入口」
     │    │区画│    │
     │    └───┘    │
     │  外周第三区画  │
     └─────────────┘
            南
```
- **中央区画**:都市の真ん中。**式典会場**がある。空の下にひらけた**屋外の丸い舞台**(直径約60メートル)と、それを半円に囲む客席(全体で直径約200メートル)。客席の外側を、低い回廊の壁が囲む。舞台の背後には、地上から空へ上がった人々を描いた壁画の壁が立つ。舞台の手前の広場の中央に、直径約20メートルの円いガラスの床があり、その下の縦穴(深さ約600メートル)を通して、中心の垂れ岩の中のグラヴェインの光が見える(1話S08)。会場からは、遠くの空に小さな浮き島が見える。
- **一族の屋敷**:中央区画の北側。白と金の古い館で、書庫と放送の舞台(増幅装置の本体がある)を持つ。
- **研究棟(技術部)**:中央区画の西側。ミオの研究室がある。
- **防衛隊の格納庫**:外周第二区画(東)。外壁の内側をくり抜いて作られ、滑走路は外壁の上の甲板に伸びていて、機体はそこから外へ発進する。
- **搬入口**:東の外壁の中ほどに開いた大きな口。地上や下層からの貨物船が係留される(1話S07、7話・8話)。
- **拘留区画**:中央区画の地下。監察局が管理する白い通路(8話)。
- **古い区画・第四配管室**:都市の土台と岩の浮き島の境目にある、百年前の配管が入り組んだ区画。屋敷の裏から通じている(9話)。
- **下層の避難区画**:岩の浮き島の上部をくり抜いた区画。不時着に耐えるように作られていて、何十万人が入れる(10話・12話)。
- **格納区画**:**中心の垂れ岩の中**、都市の面から約600メートル下。グラヴェインが置かれた巨大な空洞(下の3章)。空洞の東側の壁は、垂れ岩の外側の岩肌に面していて、ここが要塞で一番厚い壁になる。外から近づけるのはここだけ。1話でレンが外から狙い、10話でガクの機体が外から破って入る。

### 浮かび方と光
- 要塞は、グラヴェインの力で浮いている。ただし岩肌に光の筋は見えない。見えるのは、施設の窓の灯りと赤い標識灯だけ。グラヴェインの光が外から見えるのは、式典会場のガラスの床から縦穴をのぞいた時だけ。
- **最大出力(10話)**:中心の垂れ岩の割れ目から青白い光が漏れ出し、外壁から青白い光の波が、輪のように外へ広がる。外壁に取りついた機体は、この波に弾かれる。
- **砕いた後(11話)**:垂れ岩の中から光の粒が噴き出したあと、要塞の標識灯が一つずつ消え、要塞はゆっくりと傾きながら降り始める。

## 3. グラヴェイン(結晶の本体)

- 形:**縦に長い、六角柱の両端がとがった結晶**(上下に尖った巨大な水晶)。高さ約120メートル、いちばん太いところの直径約40メートル。
- 色:中心は白に近い青。外側に行くほど透明。内部に、光の筋が血管のように走り、ゆっくり脈打つ。脈打つたびに、空洞全体に低い唸りが響く。
- 置かれ方:空洞の中央に、床から浮いた状態で立っている。床から約10メートル浮いていて、足もとに祖母が立てる(10話・11話)。
- **供給線(4本)**:結晶の左右の側面から、太い管が2本ずつ、空洞の壁へ伸びている。結晶の力を要塞全体に送る線。11話でシンとタクミが切る。
- **四つの結び目**:結晶の中の光の筋が集まって、ひときわ強く光る点が4つある。正面・背面・左・右の、ちょうど高さの真ん中。ここを同時に叩くと、結晶は自分の力で内側から割れる(9話・11話)。
- 砕ける様子(11話):四つの結び目からひびが走り、結晶全体が内側から白く光って、無数の光の粒になる。粒は雪のように細かく、要塞の外へ噴き出し、地上へ降る。地面に落ちると、溶けるように染み込み、地面がかすかに温かくなる。
- 足もとの装置:鎮静の増幅装置は、ここから切り出した小さな結晶の欠片(手のひらから人の頭ほどの大きさ)を動力にしている。欠片も、本体と同じ青白い光り方をする。

## 4. 機体(可変機)

### 共通のきまり
- 空の機体も地上の機体も、**戦闘機形態**と**人型形態**の二つの形に変わる。変形にかかる時間は約2秒。
- **戦闘機形態**:速く飛ぶ。追いかける、逃げる、雲の層を突き抜ける時に使う。
- **人型形態**:飛ぶことはできるが遅い。相手につかみかかる、物を持ち上げる、地上を歩く、狭い場所で戦う時に使う。
- 人型の高さは、戦闘機形態の全長の約1.2倍(変形の時に手足が伸びる)。人間がその手のひらに乗れる(6話でユナを受け止める)。

### ケストレル(カイ)
- 空の防衛隊の制式機。単座(一人乗り)。
- 戦闘機形態:全長約15メートル。細身の三角翼、二枚の垂直尾翼。銀色の機体に群青の線。
- 人型形態:高さ約18メートル(戦闘機の全長の約1.2倍。手足が伸びる)。細身。翼は背中に畳まれる。
- 武器:機首の機関砲2門。人型の時は腰の小銃。ただしカイは、作中ほとんど撃たない。
- 翼の変化:
  - 1話:レン機に左の主翼を根元から引き裂かれる。
  - 3話:左にレンの予備の翼(錆びた鉄色、地上の採掘機の翼)をつなぐ。左右で色も形も違う。一回きりの飛行で外れる。
  - 4〜6話:翼なし。人型で歩くだけ。
  - 7話以降:ソラが作った新しい両翼。地上の採掘機の骨組みに、空の無人機から剥がした銀色の合金板を継ぎ合わせたもの。継ぎ目が目立つ、つぎはぎの翼。12話の帰還でも、この翼のまま。

### アルシオン(シン)
- 空の防衛隊の隊長機。ケストレルと同じ系統で、一回り大きい。
- 戦闘機形態:全長約18メートル。濃紺に金の線。
- 人型形態:高さ約16メートル。左腕に盾、右手に小銃。

### 防衛隊の量産機(タクミほか)
- ケストレルと同じ大きさ。灰色と群青。タクミの機体だけ、肩に隊長代理の白い線が入る(9話以降)。

### レンの機体「シュライク」(第1話版)
- 古い採掘機の骨格を組み直した、地上の可変機。
- 戦闘機形態:全長約14メートル。細身。採掘用の腕を胴の下に畳んで飛ぶ。空の機体より遅いが、低い高度での小回りがきく。
- 人型形態:高さ約16.8メートル(戦闘機の全長の約1.2倍)。
- 色:細身の銀灰色の装甲に、翼の前縁と機体の帯が深紅。ところどころに、ソラが打ち直した継ぎ板がある。
- 武器:銃はない。左腕に**掘削爪**(大きな三本の爪)、右腕に**牽引用ワイヤー**。
- 操縦席の後ろに補助席がある(4話)。
- 11話で、左腕を根元から失う。

### ガクの機体
- 大型の採掘機を組み直したもの。黄色と黒の縞。人型の高さ約18メートル。
- 左腕に掘削爪、右腕に**杭打ち砲**(採掘用の太い杭を打ち出す)。
- 操縦席の隅に、若い頃のガクとマサと幼いレンの写真が貼ってある(9話・11話)。

### ガク派のほかの機体
- 古い作業機や採掘機を組み直したもの。形も色もばらばら。どれも銃はなく、爪やワイヤー、削岩機を武器にする。

### 移動艇・貨物船・救助艇
- 移動艇:要塞と地上を行き来する、白い小型の連絡艇。空中政府の紋章が側面にある(6話)。
- 偽装貨物船:地上の古い輸送船。荷台に、覆いをかけて機体を積める(1話・7話)。
- 救助艇:要塞の格納庫に百年しまわれていた、白い古い救助艇。30隻(11話・12話)。

## 5. 空中戦のきまり(ドッグファイト)

### 要塞のまわりの飛び方
- 防衛隊の哨戒は、外壁の外側、壁から30〜100メートルの距離を、**反時計回り**に周回する。二機一組。
- 外周は第一〜第四の区画に分かれていて、区画ごとに担当の組が決まっている(1話でタクミは第三区画)。
- 発進は、東の格納庫から外壁の上の甲板を滑走して外へ出る。

### 外壁から百メートルの規定(1話S03)
- 外壁と、岩の浮き島の岩肌から百メートル以内では、発砲が禁じられている。外れた弾が、壁や岩の内側の街や区画に当たるため。
- そのため、地上の機体は**外壁すれすれ**や、**尖った岩のあいだ**を飛ぶ(1話・9話)。空の機体は、そこを撃てない。岩の浮き島の下側は、足場や配管、細い滝が入り組んでいて、小回りのきく地上の機体に有利な場所になる。
- 空の機体がそれに対抗する方法は一つ。人型に変形して組みつき、外壁から引き剥がして、壁から離れたところで戦う(1話S14、9話S04)。

### 空の機体と地上の機体の違い
- 空の機体:速い。高い高度で強い。銃を持っている。
- 地上の機体:遅い。銃がない。だが頑丈で、力が強く、低い高度や狭い場所で小回りがきく。
- だから戦い方は、空の機体が「追いかけて撃つ」、地上の機体が「張りついて、つかむ」になる。

### 雲海
- 雲の中に入ると、視界がなくなる。地上の部隊は、雲の下から一斉に浮上して奇襲する(9話)。
- 撃墜された機体は、雲を突き抜けて地上へ落ちる。

### 破片の危険(9話)
- 要塞の真下は第七区画の町。外壁の近くで撃ち合うと、破片が雲を抜けて町に降る。カイが外壁から機体を剥がす理由の一つ。

## 6. 地上

- **大地と空**:茶色くひび割れた大地。砂ぼこりで、空はいつも茶色くかすむ。11話で結晶の粒が降ったあと、空は少しずつ青くなる(12話)。
- **採取塔**:鉄骨を組んだ高さ約200メートルの塔。地中深くへ管を下ろして、地殻から結晶を絞り出している。いつも低く唸っている。11話で、唸りが止まる。
- **ユナの町(第七区画)**:採取塔のふもとの、古い家が並ぶ小さな町。中心に、古い体育館を直した避難所がある。町外れに旧バス車庫(ソラの仕事場)と、町を見下ろす高台がある。
- **封鎖の柵**:鉄の柵と有刺鉄線。出入り口に、空の歩兵の詰所(3話以降)。
- **旧坑道**:二十年前に掘り尽くされた鉱石の運搬路。柵の下を通って、サカイ町の外れの谷に抜ける。
- **丘の中継塔**:ノエが管理する、古い電波塔。百年前に地上と空をつないでいた、採掘用の回線の中継点。
- **盆地(旧採取跡)**:第七区画の東、約3キロ。採掘で地面が大きくくぼんだ、人の住んでいない土地。12話で、要塞がここに不時着する。
