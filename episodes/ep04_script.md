# 断層のグラヴェイン 第4話「空の歌姫」 脚本(第1稿)

- 尺:約22分(アバン約1分/OP 90秒/Aパート約9分/Bパート約9分30秒/ED 90秒)
- シーン数:15
- 台詞量の基準:台詞に使える時間は1,080秒(全尺1,320秒から、OP・ED・挿入歌の計240秒を引く)。会話と地上戦の混ざった回なので、ペラ2枚の基準(1分400字)で尺に収まる約7,000字を目標とする。
- 台詞の実績:6,954字(ペラ2枚換算 約1043秒/3コマ換算 約869秒。台詞に使える時間は1,080秒)
- 時間の流れ:3話から5日後の、1日。
- ケストレルは翼がないので飛べない。戦闘は人型での地上戦。
- 【伏線 ○○】は伏線管理表のIDを指す。
- ト書きの【状況】は、なぜそうなったのかの説明。【戦闘】は、機体の動きと戦い方の説明。
- 機体、要塞、グラヴェインの形や大きさ、空中戦のきまりは `episodes/world_visual.md`(美術・メカ設定書)を前提にする。

### この話の前提(作画用)
- 封鎖:3話でカイとレンが壊した柵は、翌日に空の部隊が立て直した。今度は柵の外側に空の歩兵の詰所が置かれ、出入り口は二人一組で常に見張られている。配給は、封鎖への見せしめとして半分に減らされたまま。
- ケストレル:3話の継ぎはぎの翼は、着地の時に根元から外れた。翼がないので飛べない。脚と腕は動くので、人型で歩くことはできる。旧バス車庫の奥に、幌をかぶせて隠してある。
- レンの機体:古い採掘機を組み直した地上の可変機。武器は銃ではなく、左腕の掘削爪と、右腕の牽引用ワイヤーだけ。戦闘機形態でも飛べるが、空の機体ほど速くない。操縦席の後ろに、かつてマサがレンに操縦を教えるために使った補助席があり、ソラが二人乗りできるように付け直している。柵の内側に置くと空に見つかるため、3話のあとは、旧坑道のサカイ町側の出口に近い岩陰に隠してある。ソラが付けた遠隔装置で、無人で歩かせることだけはできる。
- アルシオン:空の防衛隊の隊長機。ケストレルと同じ系統の可変機。人型の時は、小銃と腕の盾を持つ。
- サカイ町:第七区画の東隣の町。封鎖の対象ではないが、住民の多くが封鎖された町に親戚を持つ。ユナの町からは、旧坑道を通って歩いて約一時間。
- 増幅装置(小型):式典の装置を小さくしたもの。グラヴェインから切り出した結晶の小片を動力にしている(仕組みは8話で明かす)。スピーカーと一体で、歌声に鎮静の効果を乗せる。効果はスピーカーの正面ほど強く、舞台の横や後ろにはほとんど届かない。トウカは、ただの音響の機材だと思っている。
